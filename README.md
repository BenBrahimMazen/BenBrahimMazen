I build ML systems that run in production — not notebooks that stay on GitHub. Final-year Data Science / ML student at *ESSAI (Université de Carthage)*, three internships in, always shipping something new.

### 🚀 What I've built

| Project | What it does |
|---|---|
| 🔹 [*AutoAnalyst Finance*](https://github.com/BenBrahimMazen/AutoAnalyst-Finance) &nbsp;·&nbsp; [Live demo](https://mazen-ben-brahim--autoanalyst-finance-frontend.modal.run) | 5-agent LangGraph system generating full investment reports (DCF, sentiment, risk) in under 2 minutes |
| 🔹 [*ArXiv RAG Chatbot*](https://github.com/BenBrahimMazen/arxiv-rag) &nbsp;·&nbsp; [Live demo](https://benbrahimmazen-arxiv-rag.hf.space) | Hybrid retrieval + cross-encoder reranking, RAGAS-evaluated, cited answers |
| 🔹 [*Credit Scoring System*](https://github.com/BenBrahimMazen/credit-scoring-sni) | Basel II/III PD model, AUC-ROC 0.884, interpretable WoE scorecard |
| 🔹 [*Fraud Detection System*](https://github.com/BenBrahimMazen/fraud-detection-system) | Production ML pipeline — XGBoost, SHAP, FastAPI serving |
| 🔹 [*Real-Time Crypto Platform*](https://github.com/BenBrahimMazen/financial-data-platform) | Kafka streaming + Isolation Forest anomaly detection |
| 🔹 [*ESG Text Classifier*](https://github.com/BenBrahimMazen/esg-classifier) | Fine-tuned FinBERT/DistilBERT, multi-label classification |
